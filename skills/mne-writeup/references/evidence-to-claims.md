# Evidence to claims

This guide adapts academic-paper-strategist (claim design and reviewer objections) and
academic-paper-composer (outline-driven drafting and consistency checks) to empirical
neurophysiology output. It is self-contained; neither external skill is required to run MCP.
It does not import their philosophy-specific citation quotas, originality scores, paper
lengths or platform choices. Do not automatically launch a manuscript or submission workflow.

## Strategy before prose

For a meaningful analysis result, establish:

1. Question and scope: target contrast, population, observation unit, exploratory/confirmatory status.
2. Evidence inventory: source object/file, actual parameters, statistic/metric, units, axes,
   independent n, exclusions, uncertainty, correction family and relevant figure.
3. Claim boundary: descriptive pattern, predictive performance, association or corrected inference.
4. Alternative explanations: preprocessing, reference, leakage, rank, artifacts, multiple testing,
   and whether the design can distinguish the proposed mechanism from alternatives.
5. Missing evidence: separate absent metadata from analyses not performed. Ask targeted questions
   when absence prevents interpretation; do not infer clinical meaning or a causal mechanism.

Method defaults are computational settings, not universal scientific recommendations.
The user's scientific choices govern the plan; automated checks cannot certify them.

## Output contract

Use the user's language and keep the first answer short. Expand only where risk requires it:

| Section | Required content |
|---|---|
| Finding | What the actual data/metric shows, with source and units |
| Evidence | n, test direction, corrected p and family, or explicit absence of inference |
| Interpretation | What that evidence supports under stated assumptions |
| Limitations | What it cannot establish; unresolved methodological warnings |
| Missing information | Missing CI/effect size, design, labels or provenance; no fabricated placeholders as facts |
| Results draft | Short, evidence-bound paragraph, visibly awaiting design/methodology review |

The server currently emits these sections automatically for `mne_decode` and
`mne_decoding_group_test`, and scientific checks for `mne_filter`. Other tools still need
agent-led interpretation using the relevant specialist skill and this contract. A free-code
result must be audited explicitly; it does not inherit dedicated-tool validation.

`descriptive_only` means no inferential test accompanied decoding. `requires_design_review`
means numerical inference was computed but independence, assumptions and scientific meaning
still need verification. `processed_not_quality_certified` means preprocessing completed,
not that data quality has been established. None of these is a publication approval.

## Claim boundaries by workflow

| Workflow | Can describe | Do not infer without further evidence |
|---|---|---|
| Preprocessing | Applied parameters and observed before/after changes | Artifact-free data or unbiased analysis from successful execution alone |
| ERP/topography | Amplitude, polarity, latency, sensor distribution | A named component or anatomical generator from appearance alone |
| TFR | Power/ITC changes, normalization and axes | Corrected condition effects, phase coupling from power, temporal precision beyond wavelet support |
| Connectivity | Estimated metric for computed ordered edges | Causality, anatomical pathways, symmetry or absence of reference/volume-conduction bias |
| Decoding | CV discrimination and descriptive peak | Significance from >0.5, precise onset, causal coding or reactivation from off-diagonal scores |
| Group max-t | Corrected pointwise evidence in the specified family | Above-chance direction from a two-sided rejection without checking signed effects |
| Group cluster | Corrected cluster evidence and descriptive extent | Individual significant cells, exact onset/offset, equivalence after a negative test |
| Source estimates | Estimates conditional on head model, inverse and regularization | Ground-truth generators or individual localization from template anatomy |

## Composer quality check

Before presenting a draft, compare every number to the source. Verify the observation unit,
event labels, metric, coordinate axes, units and reference. Distinguish folds from subjects,
cluster p values from point p values, and descriptive ranges from CIs. Report a minimum p
as a minimum across the family, not as a selected cell's value. Do not call nonsignificance
equivalence, absence of information, or evidence for the null.

Check that Methods describes the actual procedure and Results does not add causal claims.
Discussion may offer hypotheses, labelled as hypotheses and backed by verified literature.
No citations are generated by the server's numerical template. Add references only after
verification. Missing CIs or standardized effects remain missing and are not inferred from
p values. Statistical correctness does not establish clinical utility or population prevalence.

If a quality check fails, revise the claim or mark the draft incomplete. Do not assign an
invented numeric quality score or silently turn a warning into a PASS.
